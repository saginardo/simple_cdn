# 节点月流量

节点列表显示当前 UTC 自然月的网卡收发总量；节点详情显示当前月的接收、发送与合计，以及最近 12 个有记录的月份。统计从升级后的 Agent 首次上报开始，不回填更早的月份。

## 数据来源与取舍

- Edge Agent 已从 `/proc/net/dev` 读取内核累计字节数用于实时速率。月统计复用同一所选接口：优先 IPv4 默认路由接口，否则在只有一个非 loopback 接口时选它，再否则汇总非 loopback 接口。
- 每份完整机器报告额外带所选接口的 RX/TX 累计字节和 `/proc/sys/kernel/random/boot_id`。控制面把最近采样及月汇总保存在 SQLite，按 UTC 月份累加相邻采样的差值。Agent 或控制面短暂重启、控制面暂时不可达且主机未重启时，下一次报告仍可从内核累计值补上中间流量。
- vnStat 可以直接提供逐月统计和 JSON 输出，且有独立守护进程维护本地数据库。不过它需要在每台已部署节点额外安装、启用、监控并备份数据库，还要处理与 Agent 所选接口的对应关系。当前功能只需要现有的网卡计数器和节点月汇总，采用内置采集，避免新增节点服务。

## 完整性与边界

- 首次采样只建立基线，所在月份标记为“统计不完整”。主机重启、接口切换、计数器回退或相邻采样超过 45 天时，跳过无法确定的差值并标记相关月份不完整。
- 连续采样跨过 UTC 月初时，按采样间隔分摊两侧月份的字节，保持总量不变，并标记“跨月估算”。历史月在月末之后仍缺少边界采样时也显示为不完整。
- 网卡收发量包括主机上该接口的其他服务及协议流量，不等于 Nginx 站点流量、出口计费流量或云厂商账单。接口回退为“all”时，虚拟接口和隧道可能导致重复计数。计费核对仍应以服务商的口径为准。
- 旧版 Agent 不提供累计字节，节点页显示空值；升级 Agent 后开始采集。月汇总包含在控制面 SQLite 备份中，删除节点会一并删除其月记录。
